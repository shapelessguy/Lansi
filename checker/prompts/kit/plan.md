# The plan

Said above the numbered list of the points that each thing made is to practise. `repeated` is told when the points are fewer than the things made, so that some come more than once.

## Prompt: once

Make them in this order, each centred on the rule named for it.

## Prompt: repeated

Make them in this order, each centred on the rule named for it. Where the same comes more than once, practise another side of it.
