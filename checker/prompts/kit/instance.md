# Which instance is being made

Told to an exercise that is done several times, after the tutor's brief, on lines of its own: which of its instances it is making now, so that a brief that says what each instance is to be is followed one instance at a time.

Variables:
- `$number`: which instance is being made, counted from 1
- `$total`: how many instances there are

## Prompt

You are making instance $number of $total now, each made by itself. Where the brief says what each instance is to be, such as "Set $number" or "Round $number", make what it says of instance $number, and nothing of the others.
