# The topics

The topics of the session: `none`, `one`, or `several`, which are `mixed` when the session says to mix them. A topic with a description is told as `described`.

Variables:
- `$topic`: the one topic
- `$topics`: the topics, joined by ;
- `$title`: the title of a topic
- `$description`: the description of a topic

## Prompt: none

Topic: everyday life.

## Prompt: one

Topic: $topic.

## Prompt: several

Topics: $topics.

## Prompt: mixed

Topics: $topics. Mix them: bring them together in the same sentences where it makes sense, so that every topic comes up.

## Prompt: described

$title ($description)
