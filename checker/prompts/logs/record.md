# What the learner did

What is said of what the learner did in an exercise: each instance with its grade, and what was `given`, `written`, corrected and noted under it, each name on a line and its text indented below; or, where there are no grades, as in a conversation, what the exercise and the learner wrote, one to a line.

Variables:
- `$number`: the number of the instance
- `$result`: right, wrong or partial
- `$text`: what was written

## Prompt: instance

Instance $number, graded $result

## Prompt: given

Given by the exercise (not the learner's)

## Prompt: written

Written by the learner

## Prompt: correction

Correct

## Prompt: note

Note

## Prompt: nothing

(nothing)

## Prompt: exercise

Exercise: $text

## Prompt: learner

Learner: $text
