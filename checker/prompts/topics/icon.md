# Icon of a topic

What the image model is told to draw as the icon of a topic. Only the thing itself is asked for. It is drawn on white, which is taken away after, as image models cannot draw on nothing: what is shown is the symbol alone.

Variables:
- `$topic`: the topic, with its description

## Prompt

$topic: one simple, bold symbol of it, alone on plain white. Flat colours, strong shapes. No text, letters or numbers.
